# hxyfront-62008 烟花燃放脚本编排 · 场地复用台

源提示词编号：10

面向巡演编排师的场地复用样例页：预置两套场地（滨江会展中心 / 湖畔露天剧场）与一场三段节目《江河颂》。复制旧场地脚本后按点位编号重算发射角与爆开影响范围，音乐锚点时刻保持不变，已锁段落不自动改编。若新点越界、相邻范围相交或后续节点越过节目结束（含场地宵禁），则停止切换并列出冲突，修好再提交。页面包含时间轴、点位平面图、版本对照，草稿同步保存到 localStorage。

## 代码结构

- `src/model.ts` — 业务模型：场地 / 节目脚本 / 复制重算规则
- `src/validate.ts` — 校验：越界、范围相交、越过节目结束
- `src/App.tsx` — 页面：时间轴、点位图、版本对照、冲突修复台

## 技术栈

React + Vite + TypeScript
