# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 场地复用台

巡演换场地复用旧脚本时，预置两套场地（滨江剧场 / 湖畔巡演场）与一场三段节目（终章已锁定）：

- 「复制并改编」按点位**编号**重算发射角（瞄准新场地观众锚点）与爆开范围（按锚点距离等比缩放）；
- 音乐锚点时刻保持不变，已锁段落不自动改编（可在草稿中手动修正、单节点重算）；
- 三类冲突阻断切换并列出清单：新点越界（编号缺失 / 爆开出界）、相邻节点影响范围相交、后续节点越过节目结束或场地宵禁；修好再提交；
- 时间轴、点位图、版本对照齐全；草稿与已提交版本通过 localStorage 同步保存。

代码拆成三个文件：`src/model.ts`（业务模型与改编规则）、`src/validate.ts`（冲突校验）、`src/App.tsx`（页面）。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```
